The AI part,
honestly.

A campaign rarely needs one ad. It needs fifty, on brand, by Friday. So I built a pipeline that renders whole series while I stay on the pixels. Keep scrolling, it goes sideways.

01

Deconstruct the brand

Colors, type, tone, offer. I pull the real tokens out of the client's funnel, so every ad looks like them, not like me.

Navy Gold Ice

navy carries the trust,

gold only shows up where money talks.

02

Design the layout system

Not one ad. Ten layout families that can carry any hook: listicle, quote, proof, deadline, comparison. The system is the deliverable.

03

Build each ad as code

Every static is a small webpage with the brand tokens baked in. Changing a headline takes seconds, not another design file.

<div class="ad ad--report">
  <h1>Deutsche Sparer wissen oft nicht,
      wie schnell sie im Ernstfall
      <mark>an ihr eigenes Geld</mark> kommen</h1>
  <img class="report-stack" …>
  <a class="cta">Jetzt kostenfrei sichern</a>
</div>
04

Render the whole fleet

A Python script screenshots every ad at 2160px and downscales to a crisp 1080. Fifty finals in the time one manual export used to take.

with sync_playwright() as pw:
    browser = pw.chromium.launch(headless=True)
    page = browser.new_page(
        viewport={"width": 1080, "height": 1080},
        device_scale_factor=2)
    for ad in ads:
        page.goto(ad.as_uri())
        page.screenshot(path=out / f"{ad.stem}.png")
05

Iterate on performance

The ads go live, the numbers come back, the series evolves. Same motif, tightened until the data says stop.
